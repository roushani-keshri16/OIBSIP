# 🍕 Pizza Delivery Full-Stack Application (MERN)

This repository contains the complete, professional, production-ready Pizza Delivery and Automated Inventory Management Web Application built with the **MERN Stack (MongoDB, Express.js, React, Node.js)**.

The full application codebase is organized inside the [`pizza-delivery-app/`](file:///c:/Users/roush/OneDrive/Desktop/Temperature%20Converter%20Website/pizza-delivery-app/) directory.

---

## 🚀 Quick Start

### 1. Start Backend & Database
```bash
# Seed Database with sample pizzas, inventory items, admin, and test user:
npm run seed

# Run Backend:
npm run backend
```
Backend API will be running at `http://localhost:5000`.

### 2. Start Frontend
```bash
# Run Frontend (Vite):
npm run frontend
```
Frontend Web App will be running at `http://localhost:5173`.
